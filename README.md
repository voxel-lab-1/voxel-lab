# Voxel Lab — Landing Page

Landing page de Voxel Lab: agencia de soluciones digitales (webs, apps, automatización y software a medida con IA).

- `index.html` — página lista para desplegar (autocontenida: fuentes, animaciones y estilos embebidos).
- `voxel-lab-landing.html` — copia de trabajo idéntica, usada durante el desarrollo.
- `logo-*.png` — assets originales del logo.

## Despliegue

Este proyecto es un sitio estático de un solo archivo. Cualquier proveedor de hosting estático (Vercel, Netlify, GitHub Pages) puede servirlo directamente sin build step.
